# ShopEasy - Modern E-Commerce Platform

A modern e-commerce web application built with **React 19**, **Tailwind CSS**, and **Vite**.

## ✨ Features

- 🛍️ **Interactive Product Catalog**: Real-time category filtering (Men, Women, Footwear, Electronics, Accessories) and search.
- 💰 **Price Range Slider & Sorting**: Sort by Popularity, Rating, Price Low-High, Price High-Low, and Newest.
- 🔍 **Product Quick View**: Color and size selectors, stock status, and instant cart additions.
- 🛒 **Cart Drawer & Checkout**: Slide-over cart with free delivery progress meter, promo coupon support (`SHOPEASY10`, `SUPER20`), and checkout modal with receipt confirmation.
- ❤️ **Wishlist**: Save favorite items with 1-click move to cart.
- ⚡ **Lightning Fast**: Powered by Vite + Tailwind CSS with responsive layout and glassmorphism styling.

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
